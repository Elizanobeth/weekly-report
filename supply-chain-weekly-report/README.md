# 供应链信息化团队周报

这是第一版本地汇报应用。当前使用本地 Excel 模拟三张 WPS 表，先验证三表关系、周次过滤、按成员汇报和保存后自动同步；WPS 开放接口将在取得测试凭证后接入。

## 当前能力

- 使用 KPI 表、事项台账、周报记录表三组模拟数据；
- 默认读取 `outputs/excel-sync/周报模拟数据.xlsx`；
- Excel 保存后约 3 秒自动刷新 HTML，无需重启服务；
- 支持 `2026-W36`、`2026-W37` 两个周次切换；
- 只显示所选周次存在任务进展记录的事项；
- 按责任人一人一页展示，不合并同项目下不同成员的任务；
- 展示本周进展、存在问题、需要帮助和下周计划；
- 展示完成比例、当周计划比例及进度偏差；
- 团队摘要的每一项可以跳转到来源任务；
- 支持在本次本地运行期间生成“模拟最终版”；
- 保留 WPS 只读和非生产读写能力检查脚本。

## 启动

需要 Node.js 20 或更高版本。

```bash
npm start
```

浏览器打开：

```text
http://127.0.0.1:4173
```

页面上会显示当前 Excel 的保存时间和同步状态。

## 验证 Excel 与 HTML 同步

1. 保持本地服务运行。
2. 用 WPS 或 Excel 打开 `outputs/excel-sync/周报模拟数据.xlsx`。
3. 进入“周报记录表”。
4. 修改任务进展记录的“本周主要进展、存在问题、需要帮助、下周计划、当前完成比例或本周状态”。
5. 保存 Excel。
6. 等待约 3 秒，HTML 会自动刷新并提示“Excel 已保存，页面内容已自动更新”。

不要修改三个工作表的名称、第一行字段名和各类 ID。Excel 正在保存、短暂无法读取时，页面会保留上一版内容并继续重试。

## 数据来源

- `outputs/excel-sync/周报模拟数据.xlsx`：应用默认读取的可编辑数据源；
- `mock/*.json`：生成 Excel 时使用的原始模拟数据，不由页面直接读取；
- `DATA_SOURCE=mock`：Excel 不可用时可临时切回 JSON 演示模式。

模拟数据包含以下验收场景：

- 同一项目由两名成员承担不同任务；
- KPI 与非 KPI 事项同时汇报；
- 正常、有风险、需协同和已完成状态；
- 有上周记录但本周没有记录的事项，本周页面完全隐藏；
- 历史周次仍能还原当周任务与进度。

## WPS 能力检查

真实接入前请使用非生产 WPS 多维表格。配置方法见 `.env.example`，凭证只能通过本机环境变量提供，禁止提交到 Git。

只读检查：

```bash
npm run check:wps
```

写入检查需要同时满足命令参数和环境变量的双重确认：

```bash
WPS_ALLOW_WRITE=YES WPS_TEST_TEXT_FIELD=探针字段 npm run check:wps -- --write
```
